大数据分析课程环境配置：Miniconda + Spyder + PyTorch

2026-09-06 · 预计阅读 12 分钟 数据分析

背景：刚卸载了完整版Anaconda，因为太占空间了，20个G，追求轻量，改用Miniconda，建议新手还是用 Anaconda；之前习惯使用 jupyter notebook 进行数据分析，想试试 spider notebook；之前没有使用过 pytorch，试试看。

课程用途：大数据分析，使用 Spyder、PyTorch、Jupyter Notebook、Spyder‑Notebook插件

核心策略：conda 只负责创建隔离空环境，所有 Python 业务包全部使用 pip 安装，尽量不执行 conda install xxx 安装业务库

conda 与 pip 两者定位

  1. conda：跨语言环境管理器，不光管理Python，还管理C/C++底层库、CUDA、编译器，可以安装非Python软件。
  2. pip：Python官方包管理器，仅管理Python代码包。

Windows下选择conda建环境 + pip装包的原因

1. conda最大痛点：依赖求解 Solving environment 转圈

conda工作逻辑：安装包前会完整计算环境内所有包版本，保证全部包互相兼容。 当环境包数量多（spyder+pandas+numpy+matplotlib+pytorch等），求解器需要遍历海量版本组合。 旧版本conda在Windows性能很差，经常无限转圈，十几分钟无响应，甚至直接版本冲突失败。

镜像源只能提升下载速度，无法解决conda内部版本求解CPU计算开销。

pip行为：不做全局兼容性验算，收到安装指令直接下载安装，速度快。

pip不会自动保证所有包互相兼容，版本兼容风险由使用者自行控制。

2. Spyder 使用conda安装极易踩坑

Spyder基于Qt，强依赖pyqt5、qtconsole等一整套底层组件。 conda安装Spyder时会同时解析Qt相关底层库，极易出现依赖冲突、求解卡死。 很多人把Spyder装在base环境，后续安装pytorch直接把base环境彻底损坏。 pip安装Spyder直接拉取预编译Python包，绕开conda重量级依赖计算。

3. PyTorch安装场景

  • conda版本PyTorch自带完整CUDA Toolkit，安装包体积巨大；Windows conda源pytorch版本更新滞后。
  • pip安装pytorch直接使用官方whl源，版本新、下载稳定。

⚠️PyTorch不要使用清华pypi镜像，wheel包体积巨大，镜像同步延迟，必须使用官方源地址。

4. 什么场景适合用 conda install

✅适合conda安装：

  • 需要C/C++底层库：cudatoolkit、opencv底层库、MKL、fortran编译器
  • 特殊科学库：rdkit、gurobi等pip很难安装的包
  • 需要切换C/C++运行时

❌不适合conda：pandas / numpy / matplotlib / spyder / pytorch，Windows极易求解卡死。

pip带来的风险与规避

pip不会全局校验依赖，会出现A包需要库V2，B包需要库V3，pip直接强制安装，运行代码时报错。

规避手段：

  1. 环境隔离：一个项目对应一套独立环境，不要单个环境堆砌大量包。
  2. 禁止大量混用 conda install 和 pip；conda 记录识别不到 pip 安装的包，会破坏环境。

本方案：conda仅创建空白Python环境，后续全部只用pip，不执行业务包的conda install。

两套路线对比

路线A：conda创建环境 + conda安装spyder/pytorch

conda create ... + conda install spyder pandas ...

优点：conda统一管理全部包，自动处理底层库兼容 缺点：Windows求解器性能差，长时间转圈，容易冲突直接崩坏环境

路线B：conda仅创建空环境 + pip安装全部Python包（当前采用）

conda create -n ds_env python=3.11
conda activate ds_env
pip install spyder pandas torch ...

优点：不会出现conda依赖求解卡死，速度快，规避conda的bug 缺点：使用者需要留意包版本冲突；禁止使用conda install安装业务包

两条铁律

  1. 激活ds_env环境后，除conda自身维护，尽量不执行conda install。
  2. 所有Python第三方库统一交给pip。
  3. 出现莫名其妙导入报错，直接删除重建环境，比重排版本简单：
conda remove -n ds_env --all

完整操作命令（Miniconda Prompt中执行）

打开Miniconda自带的Anaconda Prompt，不要直接使用原生PowerShell

1. 创建空环境

conda create -n ds_env python=3.11 -y
conda activate ds_env

提示符变为(ds_env)代表激活成功

2. pip配置清华国内镜像源（单独一行运行）

pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple

3. 安装数据分析库、Spyder、Spyder‑Notebook、原版Jupyter

pip install spyder spyder-notebook notebook jupyterlab pandas numpy matplotlib seaborn --ignore-installed pywin32

--ignore-installed pywin32 规避Windows WinError5 拒绝访问权限报错

4. 安装PyTorch

✅有NVIDIA显卡GPU版本

pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu124

✅无独立显卡，CPU版本

去pytorch官网确认最新命令

pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cpu

启动软件

① 启动Spyder

spyder

Spyder调出notebook面板：顶部菜单【视图 → 面板 → Notebook】，可打开.ipynb，运行后可以使用Spyder右上角变量浏览器查看表格、张量。

② 原版Jupyter Notebook（网页版，个人习惯使用这个进行数据分析）

jupyter notebook

适合写报告、导出PDF作业；⚠️网页版Jupyter运行的变量不会同步到Spyder变量浏览器。

⚠️不要同时用Spyder‑Notebook和网页Jupyter打开同一个ipynb，会产生内核冲突。

环境验证代码（Spyder IPython控制台）

import torch
import pandas
print("torch版本:",torch.__version__)
print("cuda可用:",torch.cuda.is_available())
print("pandas版本:",pandas.__version__)

a = torch.rand(5,5)
b = torch.rand(5,5)
c = a @ b
print(c)

VSCode对接ds_env环境

快捷键 Ctrl+Shift+P → Python: Select Interpreter 选择 ds_env (Python3.11.x)

VSCode可以打开ipynb，但没有Spyder的变量查看器。

常见报错处理

  1. WinError5 拒绝访问：pywin32被后台Python进程占用。关闭VSCode、Spyder、全部终端，重启Miniconda Prompt再执行pip安装。
  2. spyder‑notebook面板不显示：重启Spyder，在视图菜单重新勾选Notebook面板。
  3. 包导入找不到：确认已经执行conda activate ds_env，再启动Spyder/Jupyter。

Spyder‑Notebook vs Jupyter Notebook

项目 Jupyter Notebook（原版网页） spyder‑notebook（Spyder内部插件）
本质 独立网页应用 Spyder内部插件，底层复用Jupyter内核
文件格式 .ipynb .ipynb，文件完全互通兼容
界面 浏览器网页 嵌入Spyder桌面窗口
变量查看 只能print打印，无可视化变量浏览器 ✅可直接使用Spyder变量管理器看DataFrame、张量
调试能力 调试能力弱 完整Spyder断点调试器
导出PDF/HTML 功能完善，适合课程作业提交 导出功能弱，优先交给原版jupyter
适用场景 写报告、导出作业、分享 数据分析调试，查看表格数据

使用建议：

  1. 交作业、写报告：用原版网页jupyter notebook
  2. 调试数据、看表格变量：在Spyder内部打开同一个.ipynb使用spyder‑notebook
  3. 普通脚本开发：直接写.py脚本，使用Spyder原生编辑器+IPython控制台

不需要新建第二个conda环境，两者共用ds_env一套包。

日常使用流程

  1. 打开Miniconda Prompt
  2. conda activate ds_env
  3. 根据需求启动：spyder 或者 jupyter notebook

❗不要在base环境做数据分析开发，base仅用于维护conda本身。

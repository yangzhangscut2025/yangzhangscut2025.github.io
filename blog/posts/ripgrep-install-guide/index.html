ripgrep 安装与使用指南

2026-09-13 · 预计阅读 8 分钟 技术教程

0- 为什么装

ripgrep 几乎是所有主流 AI 编程工具的“标配”搜索底层。

各工具对 ripgrep 的使用情况

AI 编程工具 与 ripgrep 的关系
Claude Code 内置 ripgrep，搜索工具（Grep/Glob）底层直接调用它，且有三级降级策略确保可用
GitHub Copilot CLI 已将 ripgrep 捆绑进 CLI，并基于它提供了 grep 和 glob 工具
Cursor 官方博客明确说明，其 Agent 框架默认使用 ripgrep 作为搜索工具
Pi Agent 内部搜索代码时优先调用 rg，未安装则回退到较慢方案
其他工具 大量 MCP 服务器（如 octocode-mcp、Open-Dev-MCP）也基于 ripgrep 提供代码搜索能力

为什么 AI 工具都选它

AI Agent 在回答问题时，需要频繁地“在项目里找代码”。ripgrep 速度快、默认遵循 .gitignore、能自动跳过无关文件，这些特性直接决定了 AI 找代码的效率。所以 Claude Code、Copilot、Cursor 都不约而同地把它作为搜索层，而不是自己重新造一个。

不需要为每个工具单独安装 ripgrep。系统里装一次，这些工具都能受益——要么直接调用系统 PATH 里的 rg，要么在系统版本不可用时回退到内置版本。装好之后，Pi、Claude Code、Copilot CLI 的代码搜索都会更快。

一、工具定位

ripgrep（命令为 rg）是一个用 Rust 编写的命令行文本搜索工具，作为 grep 的现代替代品。

核心优势：

维度 说明
速度 比传统 grep 快 10-100 倍。10GB 项目搜索关键词，grep 约 30 秒，rg 不到 1 秒
递归默认 直接 rg "pattern" 即递归搜索当前目录及子目录，无需 -r
遵循 gitignore 自动跳过 node_modules、.git、构建产物
过滤二进制 自动跳过二进制文件和隐藏文件，避免乱码
输出可读 默认彩色高亮和行号

适用场景：全项目关键词搜索、命名不一致排查、TODO 统计、硬编码检查。

与 Pi 的协同：Pi 内部执行代码搜索时优先调用 rg。未安装时 Pi 回退到较慢的搜索方式，或提示命令找不到。安装后 Pi 的代码定位效率明显提升。

二、安装方法（Windows）

2.1 推荐：winget

Windows 10/11 自带 winget，在 PowerShell 中执行：

winget install BurntSushi.ripgrep.MSVC

安装完成后关闭并重新打开终端（使环境变量更新生效），验证：

rg --version

输出 ripgrep 版本号即安装成功。

2.2 备选：Scoop 或 Chocolatey

scoop install ripgrep
# 或
choco install ripgrep

2.3 手动安装

从 GitHub Releases 下载 ripgrep-*-x86_64-pc-windows-msvc.zip，解压后将 rg.exe 所在目录加入系统 PATH 环境变量。

三、基本使用

3.1 搜索范围

命令 作用
rg "pattern" 递归搜索当前目录及子目录，自动遵循 .gitignore
rg -t py "pattern" 只搜索 Python 文件
rg -t md "pattern" 只搜索 Markdown 文件
rg -t py -t md "pattern" 同时搜索多种类型
rg -g "*.py" "pattern" 按文件模式过滤
rg --type-list 查看所有支持的文件类型
rg --hidden "pattern" 包含隐藏文件
rg -uuu "pattern" 包含隐藏文件且不遵循 .gitignore，范围最大

3.2 输出控制

命令 作用
rg -n "pattern" 显示行号
rg -C 3 "pattern" 显示匹配行及上下各 3 行
rg -A 5 "pattern" 显示匹配行及后 5 行
rg -B 2 "pattern" 显示匹配行及前 2 行
rg --files-with-matches "pattern" 只显示文件名
rg -c "pattern" 显示每个文件的匹配行数
rg --count-matches "pattern" 显示匹配总次数

3.3 匹配控制

命令 作用
rg -i "pattern" 忽略大小写
rg -v "pattern" 反向匹配（排除）
`rg “a b

四、项目实用命令

目标 命令
排查命名不一致 `rg -n “spider_index_retry
查找 ORM 表定义 rg -n "__tablename__" src/db/orm_models.py
查找适配器实现 rg -t py "class.*Adapter" src/adapters/
查找未处理 TODO `rg -n “TODO
查找硬编码 URL rg -n "https?://" src/adapters/ -g "!*.md"
查找脚本引用 rg -n "scripts/.*\.py" docs/ README.md

五、与 Pi 配合

安装 rg 后，可在 Pi 中用自然语言触发搜索：

用 rg 搜索项目中所有引用 spider_index_retry 的位置，列出文件路径和行号

Pi 会自动调用 rg 命令并返回结构化结果，输出比 Select-String 更干净，处理效率更高。

六、常见问题

问题 原因 解决
提示"找不到 rg” 环境变量未更新 关闭并重开终端，或检查 rg.exe 目录是否在 PATH
搜索不到某文件内容 被 .gitignore 排除，或为二进制/隐藏文件 加 --hidden 或 -uuu
搜索结果太多 未限定范围 用 -t 限定类型，或 -g "*.py" 限定模式
-uuu 搜索结果异常多 未遵循 .gitignore 大型项目中慎用，优先用 -t 或 -g

七、核心价值

ripgrep 是项目的"代码搜索引擎”：一条命令全项目搜索，自动过滤无关文件，速度快到几乎无感。作为 Pi 的底层搜索工具，安装后能显著提升 AI 协作效率。
